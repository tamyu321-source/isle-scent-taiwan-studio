## 這件作品能證明什麼

`tools/agent-runtime/` 提供可執行 Python 核心、FastAPI 本機介面、SQLite 狀態儲存、行為測試與原始碼下載。展示頁的五種情境由實際 Python 程式產生，涵蓋放行、雙人覆核、無權限、策略阻擋及重放拒絕。審計鏈能偵測一般資料修改，並清楚列出缺少外部錨點的限制。

面試時可以用這個原型討論：為什麼在簽發 token 前檢查任務狀態、為什麼執行時仍須重查權限與策略、如何用一筆資料庫交易處理副作用紀錄與 token 消耗，以及移往 PostgreSQL + queue/outbox 時要如何處理 worker 崩潰與重試。

1. 查實並寫清楚 Python 後端年資、正式部署的 API/資料庫/佇列經驗。若不足 5 年，這是職缺明示的硬門檻，作品不能替代。
2. 將一個真實專案整理成架構決策紀錄：需求、取捨、故障處理、Code Review 和團隊協作證據。

4. 詢問招聘方工作地點/簽證與「2+1」安排的正式條款；截圖中的描述不是保證。
